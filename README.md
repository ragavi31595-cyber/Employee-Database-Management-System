# Employee Database Management System

## Project Overview
This project demonstrates the creation and management of an Employee Database using MySQL. It includes database creation, table creation, constraints, relationships, data insertion, and SQL queries.

## Database Name
employee

## Tables Created
1. Departments
2. Locations
3. Employees

## Features
- Created database using MySQL.
- Created tables with Primary Key and Foreign Key constraints.
- Established relationships between tables.
- Applied data types and constraints.
- Inserted sample records.
- Performed SQL operations using:
  - CREATE
  - INSERT
  - ALTER
  - UPDATE
  - DELETE
## Files Included
- Employee_Assignment.sql – Contains all SQL scripts.
- README.md – Project documentation.

## Software Used
- MySQL Workbench 8.0

## How to Run
1. Open MySQL Workbench.
2. Connect to the MySQL server.
3. Open the Employee_Assignment.sql file.
4. Execute the script using the Execute button (⚡).
5. Verify the database and tables under the Schemas panel.
